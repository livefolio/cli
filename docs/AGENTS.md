# docs

## Purpose
Project documentation containing design specifications and implementation plans. These documents capture the rationale and approach for each feature before implementation.

## Subdirectories

| Directory | Purpose |
|-----------|---------|
| `plans/` | Step-by-step implementation plans (see `plans/AGENTS.md`) |
| `specs/` | Design specifications and requirements (see `specs/AGENTS.md`) |

## For AI Agents

### Working In This Directory
- Specs are written before plans; plans reference the corresponding spec
- Files are date-prefixed (`YYYY-MM-DD-feature-name.md`) for chronological ordering
- These are reference documents — read them for context on why features were built a certain way

### Common Patterns
- One spec + one plan per feature
- Specs define the "what"; plans define the "how"
